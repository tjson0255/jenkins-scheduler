ヘルプ

Jenkins のジョブを決まった時刻にキックし、予定や計画をタイムラインで管理するツールです。

画面 マウス・キーボード操作 色と模様の意味 スケジュールの状態 権限（管理者ログイン） 保留と保留解除 パラメータと変数 遅れたときの扱い バックアップと復元 よくある質問

画面

タイムライン横軸が日付、縦にアイテム（行）が並びます。スケジュールはバー、実行（run）は丸で表示します。「縦表示」をオンにすると、行が日付・列がアイテムの表になります。
1日の予定選んだ日の Jenkins の実行（時刻・状態・ビルド）と、予定メモを一覧にします。日付欄を押すとカレンダーから日付を選べます。◀▶ で前後の日、「今日」で今日に戻ります。先の日付（まだ run が作られていない日）も、スケジュールから計算した予定を表示します。アイテム名を押すと、その日のタイムラインを開きます。
アイテムアイテム（Jenkins ジョブ・予定メモ）とカテゴリの登録・編集、バックアップと復元。
ログ誰がいつ何をしたかの記録。種別・対象・操作・期間で絞り込めます。

ツールバーのスイッチ

縦表示行＝日付、列＝アイテムの表に切り替えます。
実行状況予定や実行結果の丸を表示します。オフにするとバーだけになります。凡例の各項目を押すと、状態ごとに表示・非表示を切り替えられます。
凡例色と模様の意味の一覧を表示します。

スイッチやカテゴリの折りたたみの状態は、各自のブラウザに保存されます。他の人には影響しません。

マウス・キーボード操作

横表示（タイムライン）

行の空き部分をドラッグその期間でスケジュール（予定メモの行なら予定）を作成
Shift を押しながらドラッグ表示する期間を左右に動かす
日付の目盛りをドラッグ表示する期間を左右に動かす
Ctrl を押しながらホイール拡大・縮小
バーをクリックスケジュール（または予定メモ）の詳細を開く
バーを選んでからドラッグ期間を前後にずらす。バーの端をドラッグすると期間を伸び縮みできる
丸をクリックその実行の履歴を開く
アイテム名をクリックそのアイテムの予定一覧を開く
カテゴリ名をクリックそのカテゴリを折りたたむ・開く
左上の「⊟ 折りたたむ／⊞ 展開」すべてのカテゴリをまとめて閉じる・開く

縦表示

空きセルを縦にドラッグその期間で作成
空きセルをダブルクリックその日だけの予定を作成
帯・ラベル・時刻・アイテム名をクリック詳細や予定一覧を開く
カテゴリ名をクリックその列を折りたたむ・開く（折りたたんだ列には、その日の実行件数を表示）

縦表示ではバーをドラッグして期間を変えることはできません。横表示か、詳細の「基本情報」で変更してください。

ツールバーのボタン

「今日」で今日を表示、◀▶ で前後に移動、1週・4週・3か月で表示する期間を切り替え、＋－で拡大・縮小します。

色と模様の意味

実行（丸）の状態

予定まだキックしていない
保留予定時刻にキックしようとしたが、問題があって止めた（保留と保留解除）
キュー／実行中Jenkins がキックを受け付けた（キュー）、またはビルドが動いている（実行中）
成功ビルドが成功して終わった（Jenkins の SUCCESS）
不安定ビルドは最後まで通ったが、テストの一部失敗などの問題がある（Jenkins の UNSTABLE）
失敗／中断ビルドが失敗した、または途中で止められた（Jenkins の FAILURE / ABORTED）
スキップ／見逃し前回のビルドが実行中だった・手動でスキップした（スキップ）、ツールが止まっていたなどで猶予時間内にキックできなかった（見逃し）

バー・行の模様

ドラフト作成しただけで、まだ有効化していないスケジュール。キックされない
警告要確認。Jenkins でパラメータが追加・削除された、Jenkins 側に cron が残っている など。キックは行われる
エラーキックされない。パラメータの値が Jenkins の選択肢に無い、型が変わった、ジョブが無い、保留中の実行がある など

マーク

⛔ジョブが見つからない・ビルドできない
⏰Jenkins 側の cron（定期実行）が残っている。二重に実行される恐れがあるので、Jenkins 側の設定を消す
📝予定メモのアイテム（Jenkins には接続しない、メモや計画を書く行）
∞終了日の無い（無期限の）スケジュール
保留1保留中の実行の件数

スケジュールの状態

ドラフト作成直後。キックされない。内容を確かめてから「有効化」する
有効予定時刻に自動でキックされる。有効化は、内容を承認したという意味も兼ねる
一時停止キックしない。再開すると、止めていた間に予定時刻を過ぎた回は「遅れたときの扱い」に従う
終了終了日を過ぎた
キャンセル取りやめた。未実行の回もキャンセルされる（元に戻せない）

詳細パネルの「ドライラン」で、次の回にどんなパラメータでキックされるかを、実際にはキックせずに確かめられます。「今すぐ実行」はスケジュールのパラメータでその場でキックします。

ログインなし管理者

画面右上の「管理者ログイン」でログインし、「ログアウト」で戻ります。管理者アカウントは Jenkins を操作する人だけで共有します。

保留と保留解除

保留は、予定時刻にキックしようとしたが、パラメータの値が Jenkins の選択肢に無い・キックの送信に失敗した などの問題があって止めた実行です。自動では再開しません。保留があると、画面上部に「⛔ 保留 N件」が出ます。

  1. 管理者でログインする
  2. 「⛔ 保留 N件」を押し、理由を読む（アイテムの予定一覧の「保留中」欄や、スケジュールの「実行履歴」からも同じ操作ができます）
  3. 原因を直す（例：スケジュールのパラメータを直して保存する、Jenkins 側を直す）。原因が残ったままだと、また保留になります
  4. 「保留解除」を押す。ボタンが「今すぐキックする」に変わるので、もう一度押すとキックされます

保留解除は、予定時刻からどれだけ遅れていてもその場で実行します。今さら実行しなくてよい回は「スキップ」で終わらせてください。

パラメータと変数

パラメータの項目・型・デフォルト値は Jenkins から取得します。詳細パネルの「パラメータ」で、変えたい項目にチェックを入れて値を書きます。チェックの無い項目は Jenkins のデフォルト値で送ります。

値には次の変数を書けます（例：{{schedule.label}}-{{run.date}} → v2.4.0-2026-10-05）。日時は東京時間です。

{{schedule.label}}スケジュールのラベル（バージョンなど）
{{schedule.start_date}} / {{schedule.end_date}}スケジュールの開始日・終了日
{{run.scheduled_at}}その回の予定日時（例：2026-10-05 03:00）
{{run.date}}その回の予定日（例：2026-10-05）
{{target.job_path}}Jenkins のジョブのパス

「Jenkins Job パラメータのデフォルト値変更に追従しない」をオンにすると、有効化した時点（以降はパラメータを保存した時点）のデフォルト値で実行し続けます。

遅れたときの扱い

ツールが止まっていた・一時停止していた などで、予定時刻を過ぎてからキックすることになった回の扱いです。スケジュールごとに設定します。

猶予内なら遅れて実行予定時刻から猶予（既定10分）以内なら実行する。過ぎていたら見逃しにする
遅れたら実行しない1分以上遅れたら見逃しにする

前回のビルドがまだ実行中・キュー中のときは、アイテムの「前回ビルド実行中」の設定（スキップ／キューに積む）に従います。

バックアップと復元

管理者だけが使えます。毎日決まった時刻に自動でバックアップを取ります。管理者でログインすると、アイテム画面に「バックアップ」欄が出て、一覧の確認や「今すぐバックアップ」ができます。

復元は、管理者でログインし、戻したい .db の行の「この時点に戻す」を押します。戻す直前に今の状態を自動でバックアップするので、間違えてもそこから戻せます。

よくある質問

「成功」はキックに成功したという意味？
いいえ。Jenkins のビルドそのものが成功して終わったという意味です。キックを受け付けた段階は「キュー」です。起点のジョブが下流のジョブを「終わるまで待つ」設定なら、下流の失敗も起点の結果に含まれます。
同じジョブが二重にキックされることはない？
ツールの中では、1回の予定を2回キックしないようにしています。ただし Jenkins 側に cron（定期実行）が残っていると、そちらでも動きます。⏰ が出ていたら Jenkins 側の設定を消してください。
Jenkins 側でパラメータが変わったら？
5分ごとに Jenkins から取り直し、変わっていれば警告・エラーの模様で知らせます。パラメータを開いて確かめ、保存すると「確認済み」になって警告が消えます。キックの直前にも必ず確かめ、問題があれば保留にします。
他の人と同時に編集したら？
後から保存した方の内容で黙って上書きされることはありません。先に他の人が保存していた場合は「他の人が先に更新しました」と出て、最新の内容を読み込み直します。
他の人の変更はいつ画面に出る？
画面は15秒ごとに読み直します。
