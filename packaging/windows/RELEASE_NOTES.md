Jenkins Scheduler の初版です。Jenkins のジョブを、決まった日時に、日によって違う件名・パラメータで自動キックし、予定や結果をタイムラインで管理します。

## 主な機能

- **タイムライン**（縦表示・横表示）: レーン（Jenkins のジョブ1つ、またはメモ・計画を書くテキスト）ごとにスケジューラと予定を表示。日付を選んで移動、前後へスクロールで読み足し
- **スケジューラ**: cron（定期）または1回。パラメータは Jenkins から取得した定義をもとに上書きでき、`{{run.date}}` などの変数も使える。実行前のドライラン、今すぐ実行
- **この回だけ変更**: スケジューラの設定は変えずに、その回だけ日時・パラメータを変える（取り消し可）
- **他スケジューラ停止**: 臨時のスケジューラの期間中は、同じレーンの普段のスケジューラを止める
- **1日の予定**: カレンダーで日付を選び、その日（開始時刻から24時間）の予定と Jenkins の実行を一覧
- **実行結果**: いつ・どの件名で・どのパラメータで実行し、どうなったかを一覧。期間（開始日〜終了日）をカレンダーで選び、レーン・件名で絞り込み。件名・メモ・パラメータは実行時点のものを残す
- **安全のための確認**: キック直前に Jenkins の最新のパラメータ定義で確かめ、問題があれば保留にする。二重キックの防止、同時編集の検出
- **アイテム**: カテゴリ・レーン・スケジューラの管理、検索・絞り込み、バックアップと復元（管理者のみ）
- **ログイン**: 閲覧と予定の編集はログインなしで、Jenkins の操作は共有の管理者アカウントで（Active Directory にも対応）

外部ライブラリは FastAPI・Uvicorn・SQLAlchemy・Alembic・HTTPX の5つ（依存を含めて21個）です。同梱物のライセンスは THIRD-PARTY-NOTICES.txt を参照してください。

| ファイル | 内容 |

| `jenkins-scheduler-*-windows-x64.zip` | インストール不要の zip 版（自分でサービス登録する場合） |

## インストール

1. `JenkinsScheduler-Setup-*.exe` を管理者として実行する
2. 管理者パスワード（12文字以上）と、待ち受けポート（既定 8090）を入力する
3. 完了すると Windows サービス「Jenkins Scheduler」が起動し、`http://localhost:8090/` で開けます
4. スタートメニューの「設定ファイル（.env）を開く」で Jenkins の URL・ユーザー・API トークンを書き、「サービスを再起動（設定の反映）」を実行する

- 署名していないため、初回は Windows SmartScreen の警告が出ることがあります（「詳細情報」→「実行」）
- 他の PC から開く場合は、Windows ファイアウォールでポートを許可し、HTTPS の設定（README 5.6）を行ってください
- アンインストールしても、設定（.env）とデータ（%ProgramData%\jenkins-scheduler）は残ります
